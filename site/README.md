# ABench demo site

An animated demo of how ABench is built, its evaluation modes, local discovery, verification modes and resource tiers, with a browser for all cases. All 98 cases in the current index have a bench scaffold; the page's demo data still comes from the historical process sample of B-OPT-001 and does not represent real evaluation.

## Starting

- **Double-click `start.command`**: starts a local server at http://localhost:8765 and opens the browser (uses Node if available, otherwise Python 3).
- Or run in a terminal: `node server.mjs` (optionally with a port number), or `python3 -m http.server 8765`.
- You can also double-click `index.html` directly: the data is embedded as a script, so no server is needed.

The first time you double-click `start.command`, macOS may say it "cannot verify the developer". Right-click it in Finder and choose "Open".

## Data

`data/abench-data.js` and the report copies under `reports/` are generated by running `python3 tools/build_site_data.py` from the repository root, from `index.yaml`, each case's readiness metadata, `oj.yaml` and `agent/task.md`, and the historical demo output of `cases/B-OPT-001`; other cases show only the task card, contracts and scaffold status, and formal results must come from a real runner. Training losses and judge outputs are historical simulated values and cannot be treated as leaderboard results. The list shows both repository status (such as "skeleton built") and evaluation readiness (such as "contract only/deferred"), so a scaffold is not mistaken for something that has run end to end.

The added architecture, post-training (including distillation), data-recipe, compilation, quantization, lightweight image–text, offline audio, offline code and reliability cases use an offline sandbox and Pareto objectives; the page shows only their contracts and resource metadata, never fabricated results.

Animations use only native browser capabilities with no third-party dependencies; when the system has "reduce motion" enabled, the final state is shown directly.
