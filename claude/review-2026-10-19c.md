## Framework
- `tools/harness_kit/` (copied into every standard case): stage protocol R/T/G/P, held-out inputs materialised only after the timed phase, per-stage directories with declared `carry`, parent-side metrics; optional judge baseline for relative metrics.
- `spec/standard_cases/<ID>.yaml` → `tools/build_standard_cases.py` generates task.md, interface.md, sandbox_guide.md, submission_rules.json, oj.yaml, README.md.
- `tools/prepare/<id>.py` + `tools/prepare/run.py`: sources with licences, checksums, splits, encryption, `data_lock.yaml`.
- `oj_eval.py`: new judge kind `harness`; `awaiting_data` stops after the format check.

## Decisions
- DS track standard is DS-PIPE-002 (six OpenML suite-337 datasets); DS-GBM-001 stays the pipeline-validation micro case.
- E-ACT-001 uses PushT (lerobot/pusht_keypoints + gym-pusht) instead of LIBERO.
- V-SMP-002 anchor changed to DDIM (training-free sampler of google/ddpm-cifar10-32); C-QNT-003 anchor GPTQ.
- PRO-SPD-004 is the GPT-2 Medium track (FineWeb val loss ≤ 2.92) on 4 × H100: the 124M record is now under 40 s on 8 × H100.
- MD-MNIST-003 excludes DermaMNIST (CC BY-NC).

## Verification
- 54 arXiv IDs of anchors and report references checked on arxiv.org; dataset/model revisions, licences, file names and sizes checked on Hugging Face, OpenML, Zenodo, DaRUS, GroupLens, OGB, GitHub. Some ACM DOIs could only be confirmed through search results (publisher pages blocked or rate-limited).
- Tests: 25 pass in the build container (Python 3.13, NumPy/SciPy/scikit-learn); on the device VM (Python 3.10, no SciPy/scikit-learn) all validators pass and 23 tests pass (the synthetic end-to-end tests need scikit-learn/SciPy).
