# PRO-SPD-004 example submission

Only the submission structure is described here; no simulated model, curve or score is provided. A formal submission contains at least:

- `manifest.json`: code/dependency/data/model/hardware hashes;
- an auditable entry point (a training, inference, search, kernel or domain executor depending on the case type);
- `sources.yaml`: sources and where they are actually used;
- `run.jsonl` and `artifacts.sha256` generated by the harness at run time.

Until real resources are frozen, the example directory stays empty or holds only non-evaluation documents.
