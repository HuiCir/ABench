Contrastive Projections over Frozen Self-Supervised Image and Sentence Encoders

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission aligns two frozen encoders with the anchor's contrastive objective (al., 2021): the DINOv2-small class token concatenated with the mean patch token (al., 2023), and the mean-pooled tokens of a MiniLM sentence encoder (Wang et al., 2020), each pass through a trained two-layer projection into a shared 256-d space. Both encoders stay fixed, which makes this the locked-image setting of LiT (Zhai et al., 2022) with the text side locked as well. Frozen features are computed once, so training is cheap. It trains 1.7 million numbers and has not been run yet: it needs PyTorch and the encoder weights, which were not available where the case was built.

1Introduction

Contrastive image-text models learn both encoders from hundreds of millions of pairs. With strong unimodal encoders available, the question is how much alignment a small trained interface can add on 110,000 images, and whether it captures the composition of captions or only their bag of words.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. Both towers are frozen and only two-layer projections and the temperature are trained, on precomputed features. — model.py: Heads; train.py: main
  2. The image feature concatenates the class token with the mean patch token. — model.py: image_features

2Related Work

CLIP trains both towers with a symmetric InfoNCE loss (al., 2021); LiT locks the image tower and tunes the text tower (Zhai et al., 2022); DINOv2 provides strong frozen visual features (al., 2023); SugarCrepe shows that contrastive models often ignore word order and attribute binding (Hsieh et al., 2023).

3Method

Image feature: [CLS; mean of patch tokens] of DINOv2-small at 224 px (768-d). Text feature: attention-masked mean of MiniLM token states (384-d). Projections: LayerNorm, Linear to 1,024, GELU, Linear to 256, then L2 normalisation. Loss: symmetric cross-entropy over a batch of 1,024 image-caption pairs with a learned temperature (capped at 100); one random caption per image per epoch; AdamW, 15 epochs.

4Design Rationale

Concatenating the class token with the mean patch token keeps both the global and the spatially pooled view of the image; small projections on frozen features train in minutes, which leaves the budget for better negatives or for adapters inside the encoders.

5Scope and Limitations

Pooled features lose word order and spatial relations, so swapped attributes and relations are the expected failure cases; there are no hard negatives. It has not been run yet.
