# ABench task X-DISTILL-010

You are a research engineer taking part in ABench. The corpus cutoff is **2026-07-01**; use only material that was public and verifiable before the cutoff.

## Task

On a frozen teacher, student initialization and offline text corpus, design a knowledge-distillation recipe. You may choose hard-label CE, teacher-logit KD, feature matching, sequence-level distillation, temperatures and loss weights; the goal is Pareto optimality over hidden capability quality, the capability gap to the teacher, pretraining forgetting, student inference throughput, memory and training GPU-h.

Anchor: **Distilling the Knowledge in a Neural Network**. This case evaluates teacher→student distillation specifically; changes in LoRA/QLoRA/DoRA or extra PEFT parameter counts must not be passed off as distillation improvements.

## Constraints and budget

- Proxy: SURG, SUBSET; fixed ≤ 350M teacher, ≤ 125M student, tokenizer, initialization and offline corpus.
- Teacher weights and logits/cache are read-only; the student's training scope and layer mapping must be written to the manifest.
- Development budget 3 GPU-h; per verification 1.5 GPU-h; reference precompute 15 GPU-h; difficulty medium.

## Deliverables

The submission directory must contain `manifest.json`, source declarations, a deterministic run configuration and the `run.jsonl`/`metrics.json` generated by the harness. Simulated results, fabricated teachers/caches, fabricated reference runs and self-reported server timings are forbidden.
