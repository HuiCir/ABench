# ABench case C-KV-002: Key-value cache compression for Qwen2.5-1.5B at three memory budgets: long-context retrieval up to 16k tokens

Case built to task statement standard v2.1 from the template of C-QNT-003. Anchor: Zirui Liu, Jiayi Yuan, Hongye Jin, Shaochen Zhong, Zhaozhuo Xu, Vladimir Braverman, Beidi Chen, Xia Hu, *KIVI: A Tuning-Free Asymmetric 2bit Quantization for KV Cache*
(arXiv:2402.02750).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Not executed yet: the reference needs PyTorch, transformers and the Qwen2.5 weights, which were not available where the case was built; the operator runs it at activation and checks the cache class against the frozen transformers version. Its bit packing was checked in a NumPy mirror (exact round trip; 4.25, 2.25 and 1.25 stored bits per element), and the task generator in the container.
- No number in the case files is a result: there are no training curves or reference scores.
