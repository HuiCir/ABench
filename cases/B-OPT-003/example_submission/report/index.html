Momentum-Free Factored Second Moments as a Memory-Capped Reference

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission gives a reference update rule that fits far inside the 1x optimizer-state cap: Adafactor without momentum (Shazeer & Stern, 2018). For every weight matrix it keeps only the row and column means of the squared gradient, preconditions by their rank-1 reconstruction and clips the update to unit RMS. Its state is about 0.3% of the parameter count. The anchor's Kronecker-factored preconditioners (Gupta et al., 2018) do not fit the cap for the model's large matrices, which is the tension the case is built around.

1Introduction

Adaptive optimizers spend memory on statistics of past gradients: Adam keeps two tensors the size of the model (Kingma & Ba, 2015), and full-matrix or Kronecker-factored preconditioners keep more. When optimizer memory is capped at one number per parameter, the question is which statistics buy the most curvature information for that budget.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. The anchor's left and right Kronecker preconditioners are replaced by row and column means of the squared gradient, which fit the 1x cap. — optimizer.py: Adafactor.update
  2. No first moment; updates are clipped to unit RMS instead. — optimizer.py: Adafactor.update (clip)
  3. Decoupled weight decay on matrices only. — optimizer.py: Adafactor.update (wd)

2Related Work

Shampoo preconditions each weight matrix from the left and right with inverse roots of accumulated gradient outer products (Gupta et al., 2018), which for an m × n matrix costs m² + n² numbers. Adafactor factors the second-moment matrix into row and column statistics (Shazeer & Stern, 2018), and SM3 covers parameters with sets whose maxima bound the second moments (Anil et al., 2019); both cost sublinear memory. Momentum orthogonalised by Newton–Schulz iterations uses exactly one state tensor (Jordan et al., 2024).

Sublinear second-moment estimates leave almost the whole budget unused, while Kronecker factors exceed it for the embedding matrix; designs that spend exactly the budget on the most informative statistics are the gap.

3Method

3.1Update rule

For a matrix parameter with gradient G, the rule keeps exponential averages (β₂ = 0.95) of the row means R and column means C of G² + ε, corrects their bias, and forms V = R C / mean(R). The update U = G / √V is divided by max(1, RMS(U)) so that its RMS never exceeds 1, then the step is −lr (U + 0.1 · P) with decoupled weight decay on matrices. Vector parameters keep an unfactored second moment.

3.2Complexity

State is m + n numbers per m × n matrix; each step costs O(mn) element-wise operations and no matrix products.

4Design Rationale

Dropping the first moment is the simplest way to fit any adaptive method under the cap, and update clipping replaces the stabilising effect that momentum would otherwise provide early in training.

5Scope and Limitations

Without momentum the updates are noisy, and the rank-1 second-moment estimate captures no correlation between rows and columns; almost the whole memory budget is left unused.
