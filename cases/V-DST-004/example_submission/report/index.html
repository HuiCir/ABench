Consistency Distillation of a Discrete-Time DDPM with a Squared-Error Distance

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission distils the frozen CIFAR-10 DDPM (Ho et al., 2020) into a one- to four-step generator with the anchor's consistency distillation (Song et al., 2023). The student shares the teacher's architecture and starts from its weights; its consistency function is the clean image implied by its ε-prediction. Pairs of adjacent points on a 40-step grid are linked by one deterministic DDIM step of the teacher (Song et al., 2021), and the student's output at the noisier point is pulled towards an EMA target network's output at the cleaner one. A squared-error distance replaces the anchor's LPIPS, since no pretrained feature network is allowed.

1Introduction

A diffusion model needs many network evaluations because each one only moves its sample a little along the probability-flow ODE. Distillation trains a student that jumps along the ODE in one or a few evaluations, using the teacher to define the trajectories.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. Squared-error distance instead of the anchor's LPIPS, which needs a pretrained network. — train.py: main (loss)
  2. The consistency function is the clipped clean-image estimate of an ε-predicting student on the teacher's discrete timesteps, instead of the anchor's skip-connection parametrisation in continuous time. — model.py: consistency
  3. The student is initialised from the teacher and the target network is an EMA with decay 0.999. — train.py: main

2Related Work

Progressive distillation halves the number of sampling steps repeatedly by training the student to match two teacher steps with one (Salimans & Ho, 2022). Consistency models instead enforce that all points on one ODE trajectory map to the same clean image, with the trajectory locally given by the teacher (Song et al., 2023). Rectified flow straightens trajectories by re-training on the model's own couplings (Liu et al., 2023), and adversarial or distribution-matching objectives match the distribution of one-step samples directly (Yin et al., 2024).

The anchor's best CIFAR-10 results use a perceptual distance computed by a pretrained network, which this case forbids; how to make the distance informative without one is the gap.

3Method

3.1Distillation objective

The grid is 0 = t_0 < … < t_40 = 999. For a training image x₀, an index n and noise z, x_{n+1} = sqrt(ᾱ_{t_{n+1}}) x₀ + sqrt(1 − ᾱ_{t_{n+1}}) z. The teacher's ε at x_{n+1} defines one DDIM step to x̂_n. The loss is ‖f_θ(x_{n+1}, t_{n+1}) − f_θ⁻(x̂_n, t_n)‖² with f(x, t) = clip((x − sqrt(1 − ᾱ_t) ε̂(x, t)) / sqrt(ᾱ_t)) and θ⁻ an EMA (0.999) of θ. Adam at 1e-4 after 1,000 warm-up steps, batch 128, horizontal flips. Sampling with S steps evaluates f at S timesteps from 999 down, re-noising the estimate to the next timestep in between.

3.2Complexity

Per step: one teacher forward, one target forward and one student forward and backward pass; sampling costs S student evaluations per image.

4Design Rationale

Initialising the student from the teacher makes its consistency function correct near t = 0 from the start, and the discrete DDPM grid lets the teacher's own timesteps define the ODE steps without converting to continuous time.

5Scope and Limitations

Squared error in pixel space favours blurry averages, the grid of 40 steps is fixed rather than refined during training, and no data-free or adversarial term corrects the student's errors at one step.
