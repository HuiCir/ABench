# X-ROBUST-009 example submission

Only the submission structure is described here; no model weights, simulated curves or simulated scores are provided. A formal submission contains at least manifest.json, an auditable entry point, sources.yaml and the run.jsonl/artifacts.sha256 generated by the harness.

The manifest must declare the frozen base/tokenizer versions, the public calibration split, thresholds and the OOD/abstention strategy; these fields must not change before hidden evaluation.
