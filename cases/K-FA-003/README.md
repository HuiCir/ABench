# ABench standard case K-FA-003: An attention forward kernel faster than PyTorch SDPA

Standard (reference) case of its track, built to task statement standard v2.1. Anchor: Tri Dao, Daniel Y. Fu, Stefano Ermon, Atri Rudra, Christopher Ré, *FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness*
(arXiv:2205.14135).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Not executed yet: the stage code and reference submission need PyTorch and a GPU, which were not available where the case was built; the operator runs them at activation. The blockwise online-softmax algorithm of the example was checked against exact attention in a NumPy transcription (max difference 1e-15); the PyTorch code itself has not run.
- No number in the standard-case files is a result: there are no training curves or reference scores.

- `spec/standard_cases/K-FA-003.yaml` — source of the agent-facing task statement, interface, sandbox guide and `case/oj.yaml`
