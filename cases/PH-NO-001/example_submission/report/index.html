A Linear Spectral Autoregressive Operator: A Resolution-Independent Baseline for 1D Burgers

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission gives a minimal operator-learning baseline. Each frame is transformed to Fourier space and the next frame is predicted per wavenumber as a complex linear combination of the two previous frames, with coefficients fitted by least squares over all training transitions. This is a single linear spectral layer of the kind the Fourier neural operator stacks with nonlinearities (Li et al., 2021); because it acts on physical wavenumbers it transfers unchanged to a finer grid. The model cannot represent the nonlinear steepening of Burgers' shocks, which is where entries are expected to improve.

1Introduction

PDEBench provides standardised simulations and the normalised RMSE metric for scientific surrogates (Takamoto et al., 2022). A surrogate must be accurate over a rollout and should not depend on the grid it was trained on. A linear spectral model fixes a reference point for both properties at almost no cost.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. One linear per-wavenumber second-order autoregression in Fourier space replaces the anchor's stack of nonlinear Fourier layers. — model.py: predict
  2. Coefficients are fitted by least squares over all training transitions instead of gradient training. — train.py: main

2Related Work

Burgers' equation u_t + u u_x = ν u_xx combines nonlinear advection with diffusion. Its linear part acts diagonally in Fourier space, which motivates spectral parameterisations of the solution operator; the FNO learns a truncated set of Fourier multipliers interleaved with pointwise nonlinearities (Li et al., 2021). Learned linear dynamics in a fixed basis are also the setting of dynamic mode decomposition (Schmid, 2010).

The FNO stacks nonlinear spectral layers and is trained by gradient descent; a single linear spectral layer keeps resolution independence but cannot model nonlinear steepening; that is the gap entries can address.

3Method

3.1Model

With û_t(k) the real FFT of frame t, the model predicts û_{t+1}(k) = a_k û_t(k) + b_k û_{t−1}(k) for the first 64 wavenumbers and sets higher wavenumbers to zero. For each k, (a_k, b_k) solves a complex least-squares problem over all consecutive triples of frames in the training trajectories. Prediction rolls the recursion forward 31 steps from the last two input frames.

3.2Complexity

Training costs O(N T X log X) for the transforms and O(N T K) for the K = 64 two-parameter regressions. A rollout costs O(T X log X) per trajectory, independent of the training set size.

4Design Rationale

Working per wavenumber keeps the parameter count tiny and makes the model exactly resolution independent: amplitudes are rescaled by the number of grid points so that a 512-point input is mapped to the same physical modes. Two lags let each mode represent damped oscillation rather than pure decay.

5Scope and Limitations

The model is linear and diagonal, so it cannot transfer energy between modes; shock formation in Burgers' equation is exactly such a transfer. Nonlinear operator layers, multi-step training and stability-aware rollouts are the obvious next steps.
