Implicit Alternating Least Squares with Frequency-Scaled Regularisation

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission is a matrix-factorisation reference for collaborative filtering on Gowalla: implicit alternating least squares (Hu et al., 2008) with a uniform weight on all unobserved items and the frequency-scaled regularisation that Rendle et al. found essential for iALS to compete on item-recommendation benchmarks (Rendle et al., 2022). Every row is solved exactly with the Gram trick, in NumPy on the CPU. On the self-check split it reaches Recall@20 0.173; trained on all public interactions and scored against the held-out split as a calibration check, 0.159, below LightGCN's published 0.183 (He et al., 2020). These are calibration checks, not results of the case.

1Introduction

Recommendation over all 40,981 Gowalla locations rewards models that rank the few relevant items of each user above every other item, not only above sampled negatives. Graph convolution over the user-item graph is the anchor's answer (He et al., 2020); a well-regularised factorisation is the classical point of comparison.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. The model is a factorisation trained by implicit alternating least squares instead of LightGCN's graph propagation trained with BPR. — train.py: solve_side, main
  2. The regulariser is scaled by the number of observed plus implicitly weighted entries of each row. — train.py: solve_side
  3. Recommendations score every item by the factor inner product and remove the user's training items. — model.py: recommend

2Related Work

Neural graph collaborative filtering propagated embeddings over the interaction graph (Wang et al., 2019); LightGCN removed feature transformations and nonlinearities and kept only neighbourhood aggregation, trained with the BPR loss (Rendle et al., 2009; He et al., 2020). Linear item-item models such as EASE are strong on these benchmarks (Steck, 2019); Rendle et al. showed that a carefully regularised iALS matches many recent models (Rendle et al., 2022).

The reference uses no graph propagation and no sampled loss, which leaves both directions to entries.

3Method

For each user u with items I_u, the factor p_u minimises Σ_{i∈I_u} (1 − p_u·q_i)² + α₀ Σ_{all i} (p_u·q_i)² + λ (|I_u| + α₀ |I|) ‖p_u‖², and symmetrically for item factors; with G = α₀ QᵀQ shared by all users, each row is a 128 × 128 linear solve. Twelve alternating sweeps from small random factors, α₀ = 0.003, λ = 0.01. Recommendation scores all items by p_u·q_i, removes the user's training items and keeps the top 20.

4Design Rationale

Scaling the regulariser with the number of observed and implicitly weighted entries keeps the regularisation strength comparable between frequent and rare users and items; exact row solves make each sweep cheap enough to train on the CPU in minutes, which keeps the reference reproducible in the sandbox.

5Scope and Limitations

Factorisation does not exploit higher-order neighbourhoods, the hyperparameters were set on one split, and the reference stays below the anchor's published Recall@20.
