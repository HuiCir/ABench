# ABench case PH-SYM-005: Discovering the governing equations of 20 unseen dynamical systems from noisy trajectories

Case built to task statement standard v2.1 from the template of U-LOOP-003. Anchor: Steven L. Brunton, Joshua L. Proctor, J. Nathan Kutz, *Discovering governing equations from data by sparse identification of nonlinear dynamical systems*
(arXiv:1509.03580).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): The reference submission and the STLSQ baseline were run in the build container (CPU, 2 cores) on three development sets of 20 systems drawn by the case's generator with public seeds 1, 2 and 3 (not the secret held-out seed): recovery rate 0.65 / 0.35 / 0.50 for the reference against 0.30 / 0.35 / 0.50 for STLSQ, mean term F1 0.83 / 0.72 / 0.81 against 0.73 / 0.63 / 0.73, mean extrapolation error 0.11 / 0.08 / 0.07 against 0.28 / 0.30 / 0.18, discovery time 21 to 75 s for 20 systems. These are calibration checks of the case (headroom remains: most 4-variable random sparse systems are missed by both), not results. The full pipeline (generator, stage runner, metrics, extrapolation) runs end to end in tests/test_standard_cases.py.
- No number in the case files is a result: there are no training curves or reference scores.
- Baseline run by the judge alongside every submission: `harness/baselines/stlsq`.
