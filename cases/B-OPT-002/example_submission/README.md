# B-OPT-002 example submission (search part)

This example keeps a replayable search process: `search.py`, `search_spec.yaml`, `search_log.jsonl`, `optimizer.py` and `hparam_space.yaml`.

The report package is complete: `report/index.html` uses the ABench v2 offline arXiv HTML structure, and `references.yaml` registers the Lion, Adam, AdEMAMix and learned-optimizer papers cited in the report. The report describes only the search space, the RidgeSign update rule, the design rationale and scope, with no self-reported scores.
