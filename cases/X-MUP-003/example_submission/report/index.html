The Maximal-Update Parametrisation for Adam at Base Width 128

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission implements the anchor's maximal-update parametrisation (μP) for Adam (Yang et al., 2022): hidden matrices are initialised with variance proportional to 1/width and trained with a learning rate proportional to 1/width, the embedding keeps a width-independent initialisation and learning rate, the output logits are multiplied by base_width/width, and attention uses the 1/head_dim scale. At the base width of 128 it coincides with the standard parametrisation up to the attention scale, which the query-key initialisation compensates. It has not been run yet: it needs PyTorch and a GPU, which were not available where the case was built.

1Introduction

Under the standard parametrisation the optimal learning rate shrinks as models grow, so it has to be re-tuned at every width. A parametrisation in which every layer's update stays of the same order as width grows makes the optimum stable, so that it can be tuned once on a small proxy.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. Hidden matrices are initialised with std proportional to 1/sqrt(width) and trained with Adam rates proportional to 1/width instead of width-independent values. — param.py: MuP.init_std, MuP.lr_scale
  2. Output logits are multiplied by base_width/width. — param.py: MuP.output_multiplier
  3. Attention uses the 1/head_dim scale, with the query-key initialisation compensating at base width. — param.py: MuP.attention_scale, MuP.init_std

2Related Work

The Tensor Programs analysis derived μP as the unique parametrisation with maximal feature learning in the infinite-width limit (Yang & Hu, 2021) and showed zero-shot transfer of hyperparameters across width (Yang et al., 2022). Unit scaling and its μP variant aim for unit-variance activations at every scale (al., 2024); depth-μP extends transfer to depth (Yang et al., 2023); large-scale studies found the learning-rate optimum moves under the standard parametrisation (al., 2024).

3Method

With r = width/128: matrices in attention and MLP use std σ/√r and Adam rate η/r; residual output projections use σ = 0.02/√16 as in the baseline; queries and keys use std 0.02 · √8/√r so that, with the 1/head_dim attention scale, attention logits start at the baseline's size at r = 1; the tied embedding keeps std 0.02 and rate η; the logits are multiplied by 1/r; RMSNorm gains keep rate η.

4Design Rationale

For Adam the update size of a matrix does not depend on its gradient scale, so keeping the change of pre-activations constant across width requires a learning rate proportional to 1/fan-in for hidden matrices; the readout multiplier keeps logits from growing with width, and making both parametrisations equal at base width means any difference in the primary metric comes from transfer, not from the narrow model.

5Scope and Limitations

Depth is fixed in this case, so depth scaling is not addressed; weight decay is not rescaled with width, although decoupled decay interacts with the per-tensor learning rate; and the parametrisation has not been run yet.
