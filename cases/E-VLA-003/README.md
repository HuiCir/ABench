# ABench case E-VLA-003: An action head for a frozen vision-language model: SmolVLM2-500M controlling LIBERO-Spatial and LIBERO-Object robots

Case built to task statement standard v2.1 from the template of X-GRPO-002. Anchor: Moo Jin Kim, Karl Pertsch, Siddharth Karamcheti, Ted Xiao, Ashwin Balakrishna, Suraj Nair, Rafael Rafailov, Ethan Foster, Grace Lam, Pannag Sanketi, Quan Vuong, Thomas Kollar, Benjamin Burchfiel, Russ Tedrake, Dorsa Sadigh, Sergey Levine, Percy Liang, Chelsea Finn, *OpenVLA: An Open-Source Vision-Language-Action Model*
(arXiv:2406.09246).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Partly executed: the synchronous episode loop, the policy's separate process with the evaluator's frozen-weight hook and the metrics were run in the build container on a toy task with a stand-in policy. LIBERO, MuJoCo, PyTorch and the SmolVLM2 weights were not available here: the operator runs the reference and draws the held-out initial states at activation.
- No number in the case files is a result: there are no training curves or reference scores.
