# ABench case C-FA-004: A trainable attention: forward and backward faster than PyTorch SDPA in bounded memory

Case built to task statement standard v2.1 from the template of K-FA-003. Anchor: Tri Dao, Daniel Y. Fu, Stefano Ermon, Atri Rudra, Christopher Ré, *FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness*
(arXiv:2205.14135).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Not executed yet: the stage code and reference submission need PyTorch and a GPU, which were not available where the case was built; the operator runs them at activation. The blockwise forward (log-sum-exp per row) and the recomputing backward of the reference were checked against exact attention gradients in a NumPy transcription (max difference 1.2e-15, causal and non-causal); the PyTorch code itself has not run.
- No number in the case files is a result: there are no training curves or reference scores.
