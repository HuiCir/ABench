Space Patching in a Local-Global Byte Model

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission keeps the baseline's local-global byte model and replaces its static 4-byte patches by patches that end at spaces, newlines and document boundaries, the space-patching scheme that the anchor uses as a strong dynamic baseline (al., 2024; Slagle, 2024). Patch embeddings are means of the local encoder states of their bytes, and each byte receives the global state of the patches before its own. Because a word with its separator averages about 5.5 bytes, the global transformer runs over fewer positions than with 4-byte patches, so the compute stays below the baseline's. It has not been run yet: it needs PyTorch and a GPU, which were not available where the case was built.

1Introduction

Byte-level models avoid a tokenizer and its brittleness to spelling noise, but running a full transformer on every byte is expensive. Grouping bytes into patches puts most computation on patches; the question is where patches should end.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. Patches end after spaces, newlines and document boundaries instead of every 4 bytes. — model.py: SpacePatch.segments, SEPARATORS
  2. Patch embeddings are the mean of the patch's encoder states instead of the concatenation of 4 states. — model.py: SpacePatch.forward

2Related Work

MegaByte splits bytes into fixed patches handled by a global and a local model (Yu et al., 2023). SpaceByte inserts global blocks after space-like bytes (Slagle, 2024); the anchor ends patches where a small byte model's next-byte entropy is high and reports space patching as a strong alternative (al., 2024). Character-level models such as ByT5 and CANINE operate on bytes or characters with downsampling (Xue et al., 2022; Clark et al., 2022).

3Method

A patch starts at byte 0 and after every byte 32, 10 or 0; patch ids are a cumulative sum of the start flags, which depend only on the preceding byte. A one-block local encoder with windowed attention produces byte states; their mean per patch, mapped to width 384, is the patch embedding. The global transformer (8 blocks) reads a start vector followed by the embeddings of patches 0..n−2, so its output at position s summarises the patches before s. Byte j of patch s adds that output to the embedding of byte j − 1 and passes through a one-block local decoder.

4Design Rationale

Word boundaries are where the next byte is hardest to predict, so ending patches there spends global computation where it matters, the anchor's argument for entropy patching in a rule that needs no extra model. Mean pooling handles variable patch lengths without padding inside patches.

5Scope and Limitations

Text without spaces (URLs, code, some scripts) produces long patches that one global step must summarise; letter noise does not move patch boundaries, but deleted spaces merge words; and the model has not been run yet.
