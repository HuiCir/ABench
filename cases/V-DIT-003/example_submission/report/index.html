Long Skip Connections and QK-Norm for a Small DiT

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission is DiT-S/2 (Peebles & Xie, 2023) with two changes: U-ViT's long skip connections (Bao et al., 2023), which concatenate the output of block i with the input of block 11 - i and project back to the width, and normalised queries and keys (Henry et al., 2020). The skips add about 8% forward FLOPs, inside the case's 10% allowance; the rest of the network is the baseline's adaLN-Zero transformer.

1Introduction

At 64 tokens a diffusion transformer has to carry low-level detail through all its blocks; long skips give the late blocks direct access to the early ones, as the encoder-decoder skips of a U-Net do.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. Long skips from block i to block 11 - i with a linear projection, absent in DiT. — backbone.py: Block.skip, DiT.forward
  2. Queries and keys are layer-normalised per head. — backbone.py: QKNormAttention

2Related Work

DiT conditions transformer blocks on time and class through adaLN-Zero (Peebles & Xie, 2023); U-ViT treats all inputs as tokens and adds long skips between shallow and deep blocks (Bao et al., 2023); QK-norm normalises queries and keys before the dot product (Henry et al., 2020).

3Method

The first six blocks store their outputs; each of the last six concatenates its input with the stored output of its mirror block and applies a linear layer from 768 to 384 features before the usual adaLN-Zero attention and MLP. Queries and keys are layer-normalised per head before scaled dot-product attention.

4Design Rationale

The skip projections are the cheapest way to add a U-Net's information path to a transformer; QK-norm bounds the attention logits, which matters with bfloat16 training and a fixed learning rate.

5Scope and Limitations

The 8% extra FLOPs are not compensated by removing computation elsewhere, so part of any gain may come from the extra compute. Nothing here has been trained in this build.
