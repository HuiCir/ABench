# ABench case U-LOOP-002: Adaptive test-time compute for a looped model: accuracy at three compute budgets on three reasoning tasks

Case built to task statement standard v2.1 from the template of U-LOOP-003. Anchor: Jonas Geiping, Sean McLeish, Neel Jain, John Kirchenbauer, Siddharth Singh, Brian R. Bartoldson, Bhavya Kailkhura, Abhinav Bhatele, Tom Goldstein, *Scaling up Test-Time Compute with Latent Reasoning: A Recurrent Depth Approach*
(arXiv:2502.05171).
