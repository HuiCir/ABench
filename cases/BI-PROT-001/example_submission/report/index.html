ABench:BI-PROT-001 reference submission

Per-Assay Ridge Combination of ESM-2 Wild-Type Marginals

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission scores each substitution by the anchor benchmark's standard zero-shot protein-language-model method, the wild-type marginal of a frozen ESM-2 model (Meier et al., 2021; al., 2023), computed with both the 150M and the 650M model from one forward pass of the wild type. It then uses the 64 labelled mutants of each assay to combine the two standardised scores by ridge regression shrunk towards equal weights, so that the sign and relative trust of the models adapt to each assay (Hsu et al., 2022). It has not been run yet: it needs the ESM-2 weights and PyTorch, which were not available where the case was built.

1Introduction

Protein language models assign higher likelihood to sequences that look natural, which correlates with fitness across many deep mutational scans without any labels. A few labelled mutants per assay can correct for assays whose measured property relates differently to naturalness.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. Scores of two ESM-2 sizes are combined instead of using one model. — model.py: predict
  2. The combination weights are fitted per assay on the 64 labelled mutants by ridge regression shrunk to equal weights. — model.py: predict

2Related Work

ProteinGym collects over two hundred deep mutational scans and compares zero-shot and supervised predictors (al., 2023). ESM-1v introduced masked- and wild-type-marginal scoring (Meier et al., 2021); ESM-2 scaled the models (al., 2023). Hsu et al. combined evolutionary density scores with a few labels in augmented regression (Hsu et al., 2022); MSA-based models such as EVE and alignment-free hybrids such as Tranception remain strong zero-shot baselines (Frazer et al., 2021; Notin et al., 2022).

3Method

For each model, the log-probabilities of all amino acids at every position of the wild type come from one forward pass; X{i}Y scores log p(Y at i) − log p(X at i). Both scores are standardised over the assay's mutants. With the 64 labelled mutants (standardised labels), the weights minimise ‖X_f w − y‖² + λ (64/2) ‖w − (½, ½)‖² with λ = 1, and the query mutants are scored by X_q w.

4Design Rationale

One forward pass per assay keeps the evaluation fast; two model sizes disagree in useful ways; shrinking towards equal weights keeps 64 noisy labels from overfitting, while still flipping the sign for assays where higher likelihood means lower measured score.

5Scope and Limitations

Wild-type marginals are weaker than masked marginals, nothing is learned from the 128 public assays, and the reference has not been run yet.
