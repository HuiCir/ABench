# ABench case E-RT-002: Acting while the policy is still thinking: asynchronous chunked control of a LIBERO robot under 0–300 ms of inference latency

Case built to task statement standard v2.1 from the template of X-GRPO-002. Anchor: Tony Z. Zhao, Vikash Kumar, Sergey Levine, Chelsea Finn, *Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware*
(arXiv:2304.13705).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Partly executed: the asynchronous episode loop, the separate planner and controller processes and the delay accounting were run in the build container on a toy reaching task with a stand-in policy (success falls from 1 to 0 as the injected delay grows from 0 to 6 steps); the demonstration reader and chunk targets were run on synthetic arrays. LIBERO, MuJoCo and PyTorch were not available here: the operator runs the reference and draws the held-out initial states at activation.
- No number in the case files is a result: there are no training curves or reference scores.
