Random ReLU Features with Ridge Regression: A Training-Free-Optimiser Baseline for MedMNIST

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission gives a deliberately simple baseline for the two-dataset MedMNIST task. Each image is standardised and passed through a fixed random projection followed by a ReLU, giving 4,096 random features in the sense of random kitchen sinks (Rahimi & Recht, 2007), on top of which a ridge classifier is solved in closed form, as in extreme learning machines (Huang et al., 2006). The ridge strength is chosen on the validation split. There is no gradient-based training, which makes the result reproducible and fast, and leaves convolutional models such as the anchor's ResNets (Yang et al., 2023; He et al., 2016) as the obvious direction for entries.

1Introduction

MedMNIST standardises small biomedical images at 28×28 to study lightweight models across modalities (Yang et al., 2023). The two datasets here differ in colour, number of classes and size, so a method must be generic. A random-feature model provides a floor that needs no tuning beyond one regulariser.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. A fixed random ReLU projection of standardised pixels replaces the anchor's trained ResNet backbones. — model.py: phi; train.py: fit_one
  2. A closed-form ridge readout with the strength chosen on a validation split replaces end-to-end training. — train.py: fit_one

2Related Work

A random nonlinear map followed by a linear model approximates a kernel machine (Rahimi & Recht, 2007); with a ReLU nonlinearity and a least-squares readout this is the extreme learning machine (Huang et al., 2006). Ridge regression to one-hot targets is a stable closed-form surrogate for multiclass classification.

MedMNIST's reference models are trained ResNets; random features need no training but cannot adapt their representation; this reference is the latter and leaves learned convolutional features as the gap.

3Method

3.1Features and classifier

Pixels are scaled to [0, 1], flattened and standardised per pixel. With R a Gaussian matrix scaled by 1/sqrt(d) and b uniform in [−1, 1], features are h = max(0, zR + b) plus a bias. The weights solve (HᵀH + λI)W = HᵀY for λ ∈ {1, 10, 100, 1000}; the λ with the best validation accuracy is kept. One model is fitted per dataset with its own R drawn from the seed.

3.2Complexity

With n images of d pixels and D = 4,096 features, featurisation costs O(ndD), forming HᵀH O(nD²) and each solve O(D³). Prediction costs O(dD) per image.

4Design Rationale

A closed-form readout removes optimiser choices and seed sensitivity, so differences between seeds come only from the random features. Per-pixel standardisation lets the same projection scale work for RGB microscopy and grayscale CT. Selecting λ on held-aside data is the only adaptation to each dataset.

5Scope and Limitations

Random features ignore spatial structure and translation invariance, which convolutional networks exploit; data augmentation and learned features are the main levers for entries.
