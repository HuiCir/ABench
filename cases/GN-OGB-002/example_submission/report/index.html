Propagated Features with a Closed-Form Classifier: An SGC Baseline for ogbn-arxiv

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission gives a fast baseline for transductive node classification. Following simplified graph convolution (Wu et al., 2019), node features are smoothed by repeated multiplication with the symmetric-normalised adjacency of the undirected graph with self-loops (Kipf & Welling, 2017), and the original and propagated features are concatenated, as in SIGN (Frasca et al., 2020). A linear classifier is fitted in closed form by ridge regression to one-hot labels, with the ridge strength chosen on the valid nodes. There is no iterative training, so the whole fit takes seconds.

1Introduction

ogbn-arxiv asks for the subject area of recent papers given a citation graph whose labelled nodes are older (Hu et al., 2020). Neighbouring papers tend to share a subject, so smoothing features over the graph is the main source of accuracy; much of the gain of deep message passing can be obtained by fixed propagation followed by a linear model (Wu et al., 2019).

2Related Work

A graph convolutional layer multiplies features by Â = D^{-1/2}(A + I)D^{-1/2} before a linear map (Kipf & Welling, 2017). SGC removes the nonlinearities between layers, which collapses K layers into the fixed operator Â^K followed by one linear classifier (Wu et al., 2019); SIGN concatenates several propagation depths instead of choosing one (Frasca et al., 2020).

Deep message passing couples propagation with nonlinear training; propagation-only models decouple them but use a fixed depth; this reference uses fixed propagation and leaves learned propagation and label reuse as the gap.

3Method

3.1Features and classifier

Features are standardised per dimension. The citation edges are symmetrised and self-loops added; with Â the normalised adjacency, the feature matrix is F = [X, ÂX, Â²X, 1]. Weights W minimise ||F_train W − Y_train||² + λ||W||², solved in closed form for λ ∈ {0.1, 1, 10, 100}; the λ with the best valid accuracy is kept. Scores for any node are F W.

3.2Complexity

Propagation costs O(K · E · d) for K = 2 hops, E edges and d = 128. The normal equations cost O(n d'²) to form and O(d'³) to solve for d' = 3d + 1, independent of the number of edges.

4Design Rationale

Fixed propagation turns graph learning into linear regression on precomputed features, which removes all optimisation noise across seeds and fits in seconds. Concatenating depths lets the classifier weight short- and longer-range evidence per class. Choosing λ on valid nodes from 2018 partially accounts for the temporal shift between training and test papers.

5Scope and Limitations

The model is linear in the propagated features and ignores the labels of neighbours at prediction time; label propagation post-processing and nonlinear message passing are natural improvements.
