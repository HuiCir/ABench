# B-OPT-001 example submission (RankGate)

Demonstrates the v2 submission format: `optimizer.py` + `hparam_space.yaml` + arXiv-style design report `report/index.html` + `references.yaml`.
The report explains only the design rationale and contains no experiments or numerical results. The old design.md / sources.yaml etc. have moved to `sim/legacy_example/`.
