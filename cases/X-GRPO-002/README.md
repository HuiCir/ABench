# ABench case X-GRPO-002: A reinforcement-learning objective for verifiable rewards: post-training Qwen2.5-0.5B-Instruct on Countdown and GSM8K

Case built to task statement standard v2.1 from the template of X-SFT-005. Anchor: Zhihong Shao, Peiyi Wang, Qihao Zhu, Runxin Xu, Junxiao Song, Xiao Bi, Haowei Zhang, Mingchuan Zhang, Y.K. Li, Y. Wu, Daya Guo, *DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models*
(arXiv:2402.03300).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Partly executed: the Countdown generator (every instance checked solvable by exhaustive search, trivial instances excluded), the verifiers and the metrics were run in the build container; the pipeline runs on synthetic problems in tests/test_standard_cases.py with a stand-in model. Training and generation need PyTorch, transformers and the Qwen2.5 weights, which were not available here; the operator runs the reference at activation and records the base model's accuracy next to it.
- No number in the case files is a result: there are no training curves or reference scores.

## Files

- `spec/cases/X-GRPO-002.yaml` — source of the agent-facing task statement, interface, sandbox guide and `case/oj.yaml`
  (regenerate with `python3 tools/build_standard_cases.py --case X-GRPO-002`).
- `case/agent/task.md` — the task statement the agent sees; `harness/` — every agent-visible interface file
  (`interface.md`, `sandbox_guide.md`, `stages.py`, `metrics.py`, the shared kit and any case helpers).
- `tools/prepare/x_grpo_002.py` — data preparation (sources, checks, splits).
- `example_submission/` — reference submission with its design report (`report/index.html`, `references.yaml`).
