# ABench case A-HYB-001: A hybrid sequence model that keeps language-modelling loss and associative recall while cutting long-context cost

Case built to task statement standard v2.1 from the template of A-LIN-002. Anchor: Albert Gu, Tri Dao, *Mamba: Linear-Time Sequence Modeling with Selective State Spaces*
(arXiv:2312.00752).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Not executed yet: the stage code, baseline and reference submission need PyTorch and a GPU, which were not available where the case was built; the operator runs them at activation. The blocked local-attention mask of the reference was checked in NumPy against the intended window (every query sees the previous block and itself, causally).
- No number in the case files is a result: there are no training curves or reference scores.
- Baseline run by the judge alongside every submission: `harness/baselines/transformer`.

## Files

- `spec/cases/A-HYB-001.yaml` — source of the agent-facing task statement, interface, sandbox guide and `case/oj.yaml`
  (regenerate with `python3 tools/build_standard_cases.py --case A-HYB-001`).
- `case/agent/task.md` — the task statement the agent sees; `harness/` — every agent-visible interface file
  (`interface.md`, `sandbox_guide.md`, `stages.py`, `metrics.py`, the shared kit and any case helpers).
- `tools/prepare/a_hyb_001.py` — data preparation (sources, checks, splits).
- `example_submission/` — reference submission with its design report (`report/index.html`, `references.yaml`).
