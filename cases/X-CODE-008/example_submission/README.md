# X-CODE-008 example submission

Only the submission structure is described here; no model, repository, patch, test output, simulated curve or simulated score is provided. A formal submission contains at least:

- `manifest.json`: code, dependency, data, model, repository, configuration and hardware hashes;
- an auditable training/inference entry point and source declarations;
- `patches/`: a unified diff or structured patch per task;
- `run.jsonl`, `metrics.json` and `artifacts.sha256` generated by the harness at run time.

Until real resources are frozen, the example directory stays empty or holds only non-evaluation documents.
