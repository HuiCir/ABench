Deterministic DDIM with Uniform Timesteps: The Reference Sampler for Few-Step Generation

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This submission is the anchor sampler applied to the frozen CIFAR-10 DDPM (Ho et al., 2020). DDIM with η = 0 follows a deterministic, non-Markovian reverse process that shares the trained marginals: at each of the nfe steps the network's noise prediction gives an estimate of the clean image, which is clipped to the data range and re-noised to the next, lower noise level (Song et al., 2021). Timesteps are spaced uniformly from 999 to 0 and the last step jumps to the clean image, so exactly nfe evaluations are used. Higher-order solvers of the probability-flow ODE (Lu et al., 2022; Karras et al., 2022) are the natural improvements and are left to the entries.

1Introduction

A diffusion model trained with 1,000 noise levels can be sampled with far fewer steps if the sampler treats generation as the integration of an ODE rather than as the ancestral chain. DDIM was the first such sampler and remains the reference point for few-step generation (Song et al., 2021). With only 5 to 20 evaluations, both the integrator and the placement of the timesteps matter (Karras et al., 2022).

  1. The anchor's deterministic DDIM update (η = 0) is kept, with the clean-image estimate clipped to the data range. — sampler.py: sample
  2. Uniform timestep spacing from 999 to 0, with the last step jumping to the clean image, so exactly nfe evaluations are used. — sampler.py: sample

2Related Work

For ε-prediction with x_t = sqrt(ᾱ_t) x₀ + sqrt(1 − ᾱ_t) ε, the DDIM update with η = 0 is a first-order (Euler) step of the probability-flow ODE in the variables x/sqrt(ᾱ) and sqrt(1 − ᾱ)/sqrt(ᾱ) (Song et al., 2021; Lu et al., 2022). Multistep and higher-order solvers reuse earlier evaluations to cancel the leading error term (Lu et al., 2022).

DDIM is first order; higher-order probability-flow solvers and better timestep placement reduce error at few evaluations; those are the gap.

3Method

3.1Update

Let t_0 > … > t_{n−1} be round(linspace(999, 0, n)) for n = nfe, and ᾱ_{t_n} = 1. Starting from x ~ N(0, I), each step computes ε̂ = ε_θ(x, t_i), x̂₀ = clip((x − sqrt(1 − ᾱ_{t_i}) ε̂)/sqrt(ᾱ_{t_i}), −1, 1) and x ← sqrt(ᾱ_{t_{i+1}}) x̂₀ + sqrt(1 − ᾱ_{t_{i+1}}) ε̂. Arithmetic is in float64 apart from the network.

3.2Complexity

nfe network evaluations per batch and O(nfe · n · 3072) extra arithmetic; memory for one batch of images and one noise prediction.

4Design Rationale

Clipping the estimate x̂₀ prevents the large extrapolations that a coarse first step would otherwise produce at high noise. Ending at the clean estimate rather than at t = 0 uses the last evaluation fully. Uniform spacing is the simplest schedule and leaves room for schedules that concentrate steps where the trajectory curves most.

5Scope and Limitations

A first-order integrator with uniform steps has large discretisation error at 5 to 10 evaluations; this is the gap the task asks entries to close.
