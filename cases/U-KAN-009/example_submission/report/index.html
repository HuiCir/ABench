The MLP Layer as Its Own Reference

ABench reference submissionStandard reference for task statement standard v2.1
Abstract

This reference submission returns the evaluator's baseline layer, a linear map followed by SiLU (Elfwing et al., 2018), so that the case's plumbing can be checked end to end; its error ratio is 1 up to run-to-run noise. It is the layer that Kolmogorov-Arnold networks set out to replace (Liu et al., 2024), and the one that a comparison at matched parameters and compute often finds hard to beat outside symbolic tasks (Yu et al., 2024).

1Introduction

The case asks for a layer that beats the MLP layer at equal parameters. A submission that is the MLP layer defines the zero point of the error ratio.

Changes relative to the anchor. Each item states what this submission does differently and where it is in the code.

  1. None relative to the baseline; the anchor's spline edges are not used. — layer.py: make_layer

2Related Work

KANs place learnable univariate functions, parametrised by B-splines, on the edges of the network and report better accuracy than MLPs on function fitting and PDE solving (Liu et al., 2024). A later comparison at matched parameters and FLOPs finds MLPs ahead on most tasks except symbolic formula fitting (Yu et al., 2024).

3Method

make_layer returns nn.Linear(d_in, d_out) followed by nn.SiLU, without the activation on the output layer, with PyTorch's default initialisation.

4Design Rationale

None beyond being the baseline: it lets the operator check that the evaluator's two training runs agree.

5Scope and Limitations

It is not a method; any submission should be compared with it.
