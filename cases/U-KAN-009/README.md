# ABench case U-KAN-009: A network layer that beats the MLP layer at equal parameters: held-out function fitting and Fashion-MNIST

Case built to task statement standard v2.1 from the template of A-NORM-005. Anchor: Ziming Liu, Yixuan Wang, Sachin Vaidya, Fabian Ruehle, James Halverson, Marin Soljačić, Thomas Y. Hou, Max Tegmark, *KAN: Kolmogorov-Arnold Networks*
(arXiv:2404.19756).

## Status

- Judge: `harness` (shared stage protocol `harness/abench_stage.py`), activation **awaiting_data**: the operator still has to
  freeze the data (below); until then `tools/oj_eval.py` returns `judge_pending` for this case.
- Reference submission (`example_submission/`): Not executed: the pipeline needs PyTorch and a GPU, which were not available where the case was built. The data preparation ran on the real Fashion-MNIST files and the held-out function sampler (a 5-nearest-neighbour regressor reaches a normalised test RMSE of 0.03–0.69 on the twelve functions, so they span easy to hard). The metric arithmetic is tested on synthetic stage outputs in tests/test_standard_cases.py; the operator runs the reference at activation, where its error ratio must come out near 1.
- No number in the case files is a result: there are no training curves or reference scores.
